1.6.3 NULL Handling Details in LEFT JOIN
-- Oracle:
   Method:
      NULL retention rule: Left table fully retained, unmatched fields from right table are NULL; Supports COALESCE/NVL for filling (NVL(right_table_field, default_value) is Oracle exclusive);
      Difference from INNER JOIN: INNER JOIN only matches records, LEFT JOIN includes unmatched rows from left table;

  eg:

      SELECT s.school_id, s.school_name, ss.AvgScrWrite FROM schools s LEFT JOIN satscores ss ON s.school_id = ss.school_id;

      SELECT s.school_name, NVL(ss.AvgScrWrite, 0) AS avg_write_score FROM schools s LEFT JOIN satscores ss ON s.school_id = ss.school_id;
      Optimization hint:
      SELECT /*+ LEADING(s) USE_HASH(ss) */ s.name, ss.AvgScrWrite FROM schools s LEFT JOIN satscores ss ON s.school_id = ss.school_id;

@dialect2sql@ SQL Syntax ORDER BY Clause 1. Scenarios where ORDER BY references expressions involving aggregate functions or columns not in the SELECT list but derived from grouped data 2. Function -- Oracle - Correct/Incorrect/Reason @dialect2sql@  
In Oracle, when using GROUP BY, any expression in the ORDER BY clause must either be:  
(a) a column that appears in the GROUP BY clause,  
(b) an aggregate function, or  
(c) an expression composed solely of grouped columns and/or aggregates.  
The error ORA-01791 occurs if ORDER BY includes a non-aggregated, non-GROUPed column not in the SELECT list—or more precisely, not in the GROUP BY list—even if it seems logically derivable.  
However, in the correct SQL, all ORDER BY expressions are valid:  
- SUM(oi.quantity * oi.price_per_unit) is an aggregate,  
- r.avg_rating is part of GROUP BY (via the joined subquery result),  
- The CASE expression uses only aggregates (SUM(oi.quantity)) and a grouped column (ret.return_count, which is included in GROUP BY).  
Thus, the rule: **In Oracle, every expression in ORDER BY of a grouped query must be functionally dependent on the GROUP BY list—typically by being either a grouped column, an aggregate, or a combination thereof. Avoid referencing non-grouped, non-aggregated columns or complex expressions not fully covered by the GROUP BY.**
