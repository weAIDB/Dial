Dialect Feature: CREATE DATABASE with Template, Encoding, Locale, and Connection Control Options

PostgreSQL’s `CREATE DATABASE` statement includes numerous non-standard options not found in standard SQL (which does not define database creation syntax at all). Unique PostgreSQL-specific features include:

- **Template-based cloning**: Databases are created by cloning a template (e.g., `template0` or `template1`), enabling fast initialization with predefined settings or objects.
- **Fine-grained locale control**: Options like `LOCALE`, `LC_COLLATE`, `LC_CTYPE`, `LOCALE_PROVIDER` (`libc`, `icu`, `builtin`), `ICU_LOCALE`, and `ICU_RULES` allow detailed configuration of collation and character classification behavior—far beyond typical SQL implementations.
- **Encoding specification**: Explicit character set encoding (`ENCODING`) tied to locale compatibility rules.
- **Connection management**: `ALLOW_CONNECTIONS` and `CONNECTION LIMIT` clauses control access at the database level.
- **Template flag**: `IS_TEMPLATE` allows marking a database as a template that can be cloned by non-superusers.
- **Storage strategy**: The `STRATEGY` option (`WAL_LOG` vs `FILE_COPY`) controls internal replication mechanics during creation.
- **OID assignment**: Manual OID specification (primarily for `pg_upgrade`).

These capabilities reflect PostgreSQL’s deep integration of operating system locale, encoding, and storage semantics into its database creation process—features absent from the SQL standard and most other RDBMSs.
