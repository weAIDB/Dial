1) **Syntax Structure: function_name([expression]) OVER ([PARTITION BY partition_expression, ... ][ORDER BY sort_expression [ASC | DESC], ... ][frame_clause] -- e.g., ROWS/RANGE BETWEEN...)**
2) **MySQL 8.0+, PostgreSQL, Oracle, SQL Server, SQLite all have these functions:
Ranking: ROW_NUMBER(), RANK(), DENSE_RANK(); Offset: LAG(), LEAD(); First/Last Value: FIRST_VALUE(); Bucketing: NTILE()

-- PostgreSQL:
   Method:
      Mandatory Constraint: Window functions supported in all modern versions (9.0+); OVER() clause is mandatory; PARTITION BY/ORDER BY/frame_clause fully supported (frame_clause supports ROWS/RANGE/GROUPS); NTILE(n) requires n ≥1 (n=0 triggers "NTILE argument must be at least 1" error); FIRST_VALUE()/LAST_VALUE() rely on frame_clause (default frame only includes up to current row for LAST_VALUE(), need to adjust frame to UNBOUNDED FOLLOWING);
      Error Scenario: Setting NTILE(0); using LAST_VALUE() without adjusting frame_clause (expecting last value of partition); invalid frame_clause (e.g., GROUPS BETWEEN 2 FOLLOWING AND 1 PRECEDING);
      Solution: Set NTILE(n) with n ≥1; adjust frame_clause for LAST_VALUE() (e.g., ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING); follow valid frame_clause order and syntax.
   eg:
      Error example (NTILE(0) invalid, triggers "ntile argument must be greater than zero" error):

      SELECT dept_id, emp_id, salary, LAST_VALUE(salary) OVER (PARTITION BY dept_id ORDER BY salary) AS max_salary FROM emp_salary;
      Correct example (LAST_VALUE() with adjusted frame for max salary per department):
      SELECT dept_id, emp_id, salary, LAST_VALUE(salary) OVER (PARTITION BY dept_id ORDER BY salary ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS max_salary FROM emp_salary;
      Correct example (NTILE(4) to bucket student grades into 4 levels):
      SELECT student_id, score, NTILE(4) OVER (ORDER BY score DESC) AS grade_level FROM student_scores;
