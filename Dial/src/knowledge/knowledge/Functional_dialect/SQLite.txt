1.6.1 Two-Table Joins
* INNER JOIN: Recommended standard form
     SELECT e.name, d.department_name
     FROM employees e
     INNER JOIN departments d ON e.dept_id = d.id; -- Clearly expresses the join condition

* Old-style comma list + WHERE: Legacy style (not recommended, poor readability, error-prone)
     SELECT e.name, d.department_name
     FROM employees e, departments d
     WHERE e.dept_id = d.id; -- Implicit inner join, easy to forget conditions leading to Cartesian products

Important: All modern versions recommend using explicit LEFT/RIGHT/FULL OUTER JOIN syntax.
