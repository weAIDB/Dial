原始问题: List all the frame styles and cards Allen Williams worked on and find any banned cards if there are any.
MySQL: SELECT   c.frameVersion AS `frame style`,   c.name AS `card name`,   IF(SUM(CASE WHEN l.status = 'Banned' THEN 1 ELSE 0 END) > 0, 'Banned', 'Not Banned') AS `banned status` FROM `cards` AS c LEFT JOIN `legalities` AS l   ON c.uuid = l.uuid WHERE c.artist = 'Allen Williams' GROUP BY   c.frameVersion,   c.name LIMIT 1000;

原始问题: Between San Diego and Santa Barbara, which county offers the most number of schools that does not offer physical building? Indicate the amount.
MySQL: SELECT   `schools`.`County` AS `County`,   COUNT(`schools`.`CDSCode`) AS `Number of schools that do not offer physical building` FROM `schools` WHERE `schools`.`County` IN ('San Diego', 'Santa Barbara')   AND `schools`.`Virtual` = 'F' GROUP BY `schools`.`County` ORDER BY `Number of schools that do not offer physical building` DESC LIMIT 1;

原始问题: For the client whose loan was approved first in 1993/7/5, what is the increase rate of his/her account balance from 1993/3/22 to 1998/12/27?
MySQL: SELECT   ROUND(     (MAX(CASE WHEN t.`date` = '1998-12-27' THEN t.`balance` END) - MAX(CASE WHEN t.`date` = '1993-03-22' THEN t.`balance` END)) * 1.0     / NULLIF(MAX(CASE WHEN t.`date` = '1993-03-22' THEN t.`balance` END), 0) * 100   , 2) AS `balance_increase_rate_percent` FROM `trans` AS t JOIN (   SELECT l.`account_id`   FROM `loan` AS l   WHERE l.`date` = '1993-07-05'   ORDER BY l.`loan_id` ASC   LIMIT 1 ) AS sel   ON sel.`account_id` = t.`account_id` WHERE t.`date` IN ('1993-03-22', '1998-12-27');
